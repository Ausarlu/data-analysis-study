# Day 1 学习总结：Series、DataFrame 基础

## 一、Python 语法基础铺垫

### 1. `()` 圆括号 vs `[]` 方括号
- `()`：调用/执行一个函数或方法，括号里是"喂给它的原料"（参数）。例：`pd.Series(...)`、`df.head(2)`
- `[]`：从已有的对象里，按位置或标签"取出"一部分内容。例：`s['a']`、`df['收盘价']`
- 没有括号，直接 `.属性名`：读取对象自带的信息，不是"做动作"。例：`.values`、`.index`、`.dtype`、`.shape`

### 2. 引号的作用
- 数字不加引号（`10`、`190.5`）——是数值类型，可以参与数学运算
- 文字/字符串必须加引号（`'a'`、`'AAPL'`）——告诉 Python "这是一串符号，别当成变量名或数字"
- 不加引号裸写字母，Python 会当成变量名去找，找不到就报错（`NameError`）

### 3. 索引为什么从 0 开始
- 索引表示的是"离起点的偏移量"，不是人类习惯的"第几个"
- 第一个元素离起点 0 步，所以索引是 0
- Python、C、Java 等语言都是这个惯例（R、MATLAB 是例外，从1开始）

### 4. 切片 `[起点:终点]` —— "含头不含尾"
- `lst[0:3]` 取的是位置 0、1、2，不包含位置 3
- 可以理解成"两把刀"切在数字之间的位置，而不是选中具体的数字
- **例外**：`.loc` 的切片是"含头含尾"（因为按标签算，不是偏移量逻辑），`.iloc` 和普通列表一样是"含头不含尾"

### 5. 代码缩进
- 字典/列表里的换行 + 缩进，**纯粹是给人看的排版**，压成一行效果完全一样，只是可读性差
- 官方推荐每级缩进 4 个空格
- 区别于 `if`/`for`/函数定义里的缩进——那种是**语法强制**，缩进错了代码报错，这个之后讲控制流时会细讲

## 二、Series（一维数据结构）

### 创建
```python
s = pd.Series([10, 20, 30, 40], index=['a', 'b', 'c', 'd'])
```
- 一列数据（values）+ 一列标签（index），一一对应
- 不写 `index` 参数时，默认用 0,1,2,3... 整数标签
- 同一个 Series 里的数据类型必须一致

### 取值：`.loc` vs `.iloc`
- `.loc['a']`：按**标签**取值
- `.iloc[0]`：按**位置**取值（不管标签是什么，永远数第几个）
- 直接写 `s[0]` 在有自定义标签时容易产生歧义，不推荐，明确用 `.loc`/`.iloc` 更安全

### 常用属性（都不加括号，是读取属性不是调用方法）
| 属性 | 作用 |
|---|---|
| `.values` | 取出纯数据部分（去掉标签），返回 numpy 数组 |
| `.index` | 取出标签部分 |
| `.dtype` | 查看这一列数据的类型（单数，因为 Series 只有一列） |

### 常见 dtype 类型
| dtype | 含义 |
|---|---|
| int64 | 整数 |
| float64 | 浮点数（带小数） |
| object | 字符串/文本 |
| bool | 布尔值 |
| datetime64 | 日期时间 |

## 三、DataFrame（二维表格结构）

### 创建：字典 → DataFrame
```python
data = {
    '股票代码': ['AAPL', 'MSFT', 'GOOG'],
    '收盘价': [190.5, 410.2, 175.3],
    '成交量': [58000000, 22000000, 19000000]
}
df = pd.DataFrame(data)
```
- 字典的"键" → 变成列名
- 字典的"值"（列表）→ 变成这一列的数据
- 可以理解成：**DataFrame 是好几个 Series 按列拼在一起，共用同一套行索引**

### 常用属性
| 属性 | 作用 |
|---|---|
| `.shape` | 返回 (行数, 列数) |
| `.dtypes` | 每一列各自的类型（复数，因为有多列） |
| `.columns` | 所有列名 |
| `.index` | 行标签 |

### 取值操作
- 取单列（简写）：`df['收盘价']` → 结果是一个 Series
- 取多列：`df[['股票代码', '收盘价']]`（注意双层括号：外层取，内层是列名列表）→ 结果还是 DataFrame
- 取单列的规范写法：`df.loc[:, '收盘价']`（冒号表示"这个维度全都要"）

### `.loc` / `.iloc` 完整语法：`df.loc[行, 列]`
```python
df.loc[1]                          # 标签为1的整行
df.loc[1, '收盘价']                # 标签1行 + 收盘价列 -> 具体一个值
df.loc[:, '收盘价']                # 所有行 + 收盘价列 -> 整列
df.loc[0:1, ['股票代码', '收盘价']] # 标签切片(含头含尾) + 多列
df.iloc[0:2, 0:2]                   # 位置切片(含头不含尾) + 位置列
```

## 四、今天踩过的坑
- 字符串里不小心多打了标点（如 `"GOOG,"`），逗号被打进引号内部变成了内容的一部分，而不是分隔符——实际做数据清洗时要留意这类问题，否则 "GOOG," 和 "GOOG" 会被当成两个不同的值
