# Day 2 学习总结：文件读写、条件筛选

## 一、文件读写

### 读取 CSV 文件
```python
df = pd.read_csv('股票数据.csv')
df.head()      # 默认显示前5行，快速看一眼数据长什么样
```
- `read_csv` 是 pandas 提供的函数，读取 CSV（逗号分隔值）文件，自动转换成 DataFrame
- CSV 是最通用的表格数据交换格式，本质是纯文本+逗号分隔

### 相对路径 vs 绝对路径
- **相对路径**：只写文件名（如 `'股票数据.csv'`），是"相对于当前工作目录"去找文件
  - 当前工作目录：Python/Jupyter运行时"站"在哪个文件夹，可以用 `os.getcwd()` 查看
- **绝对路径**：从硬盘根目录开始的完整路径（如 `'/Users/用户名/Downloads/股票数据.csv'`）
  - Mac/Linux 系统下，根目录用一个 `/` 表示，绝对路径必须以 `/` 开头，否则会被当成相对路径处理，导致 `FileNotFoundError`
  - 常见踩坑：漏写开头的 `/`
- `/` 表示进入子文件夹，`..` 表示返回上一级文件夹
- Mac 上查看文件路径：Finder 右键"显示简介"（中文文件夹名正常显示中文，不影响使用）；或按住 Option 键右键选"拷贝为路径名称"；或代码里用 `os.path.abspath('文件名')`

### 项目文件夹管理
- 不同用途的项目应该放在各自独立的文件夹里，不要混在一起
- 习惯：新任务先新建文件夹，再在 VSCode 里 File → Open Folder 打开，之后新建的文件都会归属这个项目

### `df.info()`：数据总览
```python
df.info()
```
一次性给出：行数、每列的非空值数量（Non-Null Count，用于发现缺失值）、每列的类型（Dtype）、内存占用
- 是**方法**（有括号），只打印报告，不返回可存储的值——这点与 `.shape`/`.dtypes`/`.columns`/`.index` 等**属性**（无括号，返回具体对象）不同
- 拿到新数据的标准检查动作：先 `.head()` 看长相，再 `.info()` 看整体情况（尤其是有没有缺失值、类型对不对）

## 二、条件筛选（布尔索引）

### 核心原理：两步走
```python
df[df['close'] > 200]
```
1. **第一步**：`df['close'] > 200` —— 对整列做"广播"比较，逐个元素判断，返回一串 True/False（布尔 Series / 布尔掩码）
2. **第二步**：`df[布尔Series]` —— True 对应的行保留，False 对应的行丢弃

### 多条件组合：不能用 `and`/`or`/`not`
- Python 原生的 `and`/`or`/`not` 只能处理单个 True/False，不能处理一整串 Series，会报错（`ValueError: truth value ambiguous`）
- 必须改用：`&`（且）、`|`（或）、`~`（非）—— 专门用于整串 Series 逐位置做逻辑运算

### 括号规则（容易踩坑，必须记牢）
- `&`/`|`/`~` 的运算优先级比 `==`/`>`/`<` 等比较运算符**更高**
- 所以只要 `&`/`|`/`~` 和比较运算混用，**每个独立的比较条件必须单独用括号包起来**，否则 Python 会按错误的顺序运算，可能不报错但结果是错的（最危险的一类bug）
```python
df[(df['close'] > 200) & (df['ticker'] == 'MSFT')]
```

### 且或混用时，必须用括号明确分组优先级
```python
# (ticker是AAPL 或 ticker是MSFT) 且 close大于200
df[((df['ticker'] == 'AAPL') | (df['ticker'] == 'MSFT')) & (df['close'] > 200)]
```
- 不加中间那层括号，会被 Python 按"&优先级高于|"的规则错误解析，导致逻辑变化（且不报错）

### 三个条件的组合写法
- 全并列（都用&或都用|）：结构规整，可以先搭好括号骨架 `( ) & ( ) & ( )`，再依次填入每个条件
- 有嵌套（且或混用）：建议"由内向外"，先写好每个最小条件，再逐层往外包成一个整体，最后再拼接

### `=` 和 `==` 的区别（极易混淆、且不报错的坑）
- `=`：赋值，把右边的值存进左边的变量名，如 `df = pd.DataFrame(data)`
- `==`：判断相等，返回 True/False，如 `df['ticker'] == 'MSFT'`
- 筛选条件里错用 `=` 会直接把整列覆盖掉（如 `df['ticker'] = 'MSFT'` 会把整列都改成'MSFT'），且不会报错，是隐蔽的破坏性错误
