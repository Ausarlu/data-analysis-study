# Day 3 学习总结：数据清洗 —— 缺失值、重复值

## 一、缺失值（Missing Values）

### 什么是缺失值 / NaN
- `NaN`（Not a Number）：pandas（依赖numpy）用来表示"这个格子没有数据"的特殊标记
- 写法：`np.nan`（numpy库里定义好的固定对象，直接引用）
- `NaN` 本质属于浮点数类型（float），所以一列里出现NaN不会把整列变成字符串类型

### 检测缺失值：`.isna()` / `.isnull()`
```python
df.isna()          # 逐个元素检查，返回形状不变的True/False表格
df.isnull()         # 与isna()完全等价，同义词(历史遗留原因)，社区更常用isna()
```
- **检查粒度：逐元素**——每个格子独立判断，跟原DataFrame形状一模一样

### 常用组合技巧
```python
df.isna().sum()                    # True当1、False当0，求和=每列缺失值个数
df[df['close'].isna()]             # 配合Day2条件筛选，把缺失的行单独挑出来看
```

### 处理缺失值：`.dropna()` 删 / `.fillna()` 填
```python
df.dropna()          # 只要这一行任意一列是NaN，整行删除
df.fillna(0)          # 用指定值填补所有NaN
```
- 两者**默认都返回新副本，不修改原数据**，必须用变量接住结果（如 `df_clean = df.dropna()`）
- `inplace=True` 参数可以直接修改原数据，但不推荐（风险高，容易误删且无法找回），更安全的习惯是始终用新变量接住

### 该删还是该填？—— 判断思路（非语法，是业务思考框架）
- 看**缺失比例**：比例低（如<1%）倾向直接删；比例高倾向填补，避免损失太多数据
- 看**缺失是零散的还是系统性的**：某一列大量系统性缺失，可能说明这一列数据源本身有问题
- 看**字段的业务性质**决定填什么：
  - 价格类数据：不宜填0（会造成"暴跌到0"假象），常用前值填充（ffill）
  - 成交量：若确实"当天无交易"，填0可能是合理的
  - 分类型数据（如ticker）：不能用均值填补，通常删除或用专门的标记值
- `.fillna()` 的具体策略选择（均值、前值填充等），留到 Week 2 结合真实金融场景细讲

## 二、重复值（Duplicates）

### 检测：`.duplicated()`
```python
df.duplicated()
```
- **检查粒度：逐行**——把整行所有列的值打包在一起判断，返回一维Series（每行一个True/False）
- 从上往下扫，第一次出现的行标False（"原版"），后面完全一样的行标True（"重复出现的"）
- 与 `.isna()` 的关键区别：`.isna()`逐元素、形状不变；`.duplicated()`逐行、结果是一维

### 处理：`.drop_duplicates()`
```python
df_clean = df.drop_duplicates()    # 删除duplicated()判定为True的行，只保留每组重复的第一条
```
- 同样默认返回新副本，不修改原数据

### `subset` 参数：只按"某几列的组合"判断重复，而非要求整行完全一样
```python
df.duplicated(subset=['ticker', 'date'])
df.drop_duplicates(subset=['ticker', 'date'])
```
- **subset里多列之间是"且"的关系**：必须列出的所有列都对得上，才判定为重复
- subset涉及的列越少 → 判定条件越宽松 → 找出的"重复"越多
- 实际业务里，`subset`比"要求整行完全一样"更常用，因为能抓出更有业务意义的重复（如"同一股票同一天出现两条冲突记录"）

### `subset=[...]` 里的 `=` 是什么？—— 关键字参数，不是变量赋值也不是判断相等
- 这是函数调用时的**关键字参数**写法：`参数名=参数值`，告诉函数"这个值要交给哪个参数"
- 只在这次函数调用内部有效，不会创建一个外部可用的变量
- 和 `x = 5`（变量赋值）符号一样但含义不同；和 `==`（判断相等）完全是两回事——这里不是在"问是否相等"，而是在"设置参数"

## 三、今天实战验证的例子（基于"股票数据_脏版.csv"，307行）
| 操作 | 结果 | 说明 |
|---|---|---|
| `df.isna().sum()` | close缺8, volume缺5 | 逐列缺失值计数 |
| `df.duplicated().sum()` | 4 | 完全重复的行数 |
| `df.duplicated(subset=['ticker','date']).sum()` | 7 | 同股票同日期的重复(条件更宽松，数量更多) |
| `len(df.dropna())` | 294 | 307-13，说明8个close缺失和5个volume缺失分布在13个不同行，没有重叠 |
| `len(df.drop_duplicates())` | 303 | 307-4 |
| `len(df.drop_duplicates(subset=['ticker','date']))` | 300 | 307-7 |
